# FACTS Feature Roadmap

Developer-only reference. Do not surface this as an end-user page.

| Area | FACTS Offers | Build Better |
| --- | --- | --- |
| System of record | Central student, family, staff, academic, communication, medical, and operational data. | Unified search, student timelines, agent-readable APIs, and explainable dashboards. |
| Attendance | Flexible attendance codes, day setups, real-time monitoring, and family alerts. | Heatmaps, risk scoring, closeout workflows, automatic follow-up lists, and trend charts. |
| Gradebook and report cards | Standards-aligned gradebook, custom grading scales, report cards, GPA, transcripts. | Missing-work aging, advisor packets, one-click charts, and intervention recommendations. |
| Behavior and discipline | Centralized incident documentation, workflows, and family communication. | Separate recognition from discipline, chart trends, and link behavior to attendance and academics. |
| Cafeteria | Menus, POS barcode scanning, balances, prepay, lunch activity, financial integration. | Keep billing last, but add allergy-safe meal views, low-balance workflows, and participation charts. |
| Health | Vaccinations, medication scheduling, conditions, parent communication. | Health and safety module with allergy alerts, medication logs, emergency exports, and permissions. |
| Scheduling | Complex K-12 schedules, block schedules, multi-campus setups. | Conflict detection, coverage gaps, live bell schedule, substitute planning, and admin alerts. |
| Enrollment | Inquiry, applications, contracts, documents, reenrollment, retention dashboards. | Admissions funnel analytics and document/task chasing before billing features. |
| Family portal and communication | Family app, email/SMS/app messaging, announcements, grades, reports, billing. | Role dashboards, message drafts from filtered lists, communication audit trail. |
| Analytics and dashboards | Unified dashboards, custom dashboard builder, admissions, demographics, behavior, report cards. | Instant chart generation on any dataset, saved chart boards, agent API access, and better filtering. |
