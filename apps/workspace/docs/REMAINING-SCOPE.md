# Remaining scope

The current release is not a complete FACTS replacement or authoritative payroll/accounting system.

| Area | Remaining work |
| --- | --- |
| Payroll | Confirmed periods and wage rules; paid breaks/overtime/PTO; gross/net, deductions/taxes, closeout and accountant acceptance. |
| Academics | Complete progression/graduation/rank/honor workflows, actual school policies, full CRUD and operational acceptance. |
| Families/admissions | Parent applications/access, documents, contracts/fees and delivered communications. |
| Care/dismissal | Program policies, parallel operational drills, parent arrival/geolocation and defined offline/emergency behavior; authorized staff retain release control. |
| Finance | Complete accounting/reconciliation/approval workflows, source ownership, document storage/scanning and retention. Attachment experiments are paused and excluded. |
| Integrations | Google OAuth/reconciliation, email delivery, validated exchange profiles and approved hosted agent connections. The current local MCP bridge is read-only. |
| Reports/imports | Broader validated templates, joins, server document/PDF generation and source mapping/reconciliation. |
| Administration | Custom roles, independent tenants/switching, support recovery and organization policies. |
| Operations | Live-record acceptance, backup/restore drills, monitoring, response/retention and authorized operational ownership. |

These are planned work, not shipped integrations. See [plan](PLAN.md), [status](STATUS.md) and [ADRs](adr/README.md).
